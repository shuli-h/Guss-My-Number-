A fully interactive browser-based game built with **vanilla JavaScript**, showcasing fundamental front-end development skills such as DOM manipulation, event handling, real-time UI updates, and game logic implementation.

This project demonstrates my ability to build real applications from scratch using core web technologies, without relying on external libraries or frameworks.

---

## 🎮 Game Overview

The goal of the game is simple:  
Guess a secret number between **1 and 20**.

### Gameplay Features:
- The user enters guesses through an input field.  
- The game provides feedback:
  - **Too high**
  - **Too low**
  - **Correct!**
- Shows the current score (starting at 20 and decreasing with each wrong guess).  
- Tracks and stores the **high score**.
- Includes a reset / "Play Again" feature.

This project highlights:
- Logical decision-making  
- State management  
- Dynamic DOM updates  
- Clean and organized code structure
